## golden rule (5제품 공통 관찰)
1. **'In Progress'는 그릇명 금지 — 컨테이너는 항상 '셀 수 있는 작업 명사'**. Change 안 와닿음의 병리는 개념이 아니라 **품사** (진행-추상명사를 명사로 옴) → '할 일'(셀 수 있음) 확정 재확인
2. routine 관리 = **2단 인라인(그룹 행+항목 행) 1화면**: 그룹 하단 입력행(값 자동상속/GitHub)+드래그 1회=속성기록+그룹 헤더 상시집계 — 내 QuickAddChangeRow(milestoneId 상속)는 GitHub 규칙과 무관하게 수렴 ✓
3. 최소동선: GitHub/Asana 3-5, Linear 키보드 5-7, Notion 6-8 → XITA 2단계 목표(Enter생성→contextMenu이동) 달성 상태
## 항목별
- Linear: 마일스톤 자동제안(생성 시), 날짜클릭=편집, 상세=클릭 속성 인라인, milestone→project 승격
- Plane: 제목만 필수+기본 백로그 상태, 상태별 카운트=카드 기본정보
- Asana: 서브태스크 보드 내 접힘 전개(화면이동0), 빈 그룹 숨김 옵션, 카드 위 연필=필드추가
- Notion: hover 전 컨트롤 숨김, 조건부 색상(overdue 빨강 행)
- GitHub: 드래그=속성기록 공식, fill-handle 복사가격
